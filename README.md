# Dira Signal

What matters. Verified.

- `index.html`: the public site (GitHub Pages, deploy from branch `main`, root folder).
- `stories.json`: verified stories. Only stories cleared on the newsroom desk are added here.
- `wire.json`: the Live wire, rebuilt every 10 minutes by `.github/workflows/wire.yml`. Headlines only, each labelled with its source and linked to the original. Never presented as verified.
- `scripts/feeds.json`: the outlets the wire watches. Add or remove feeds here.
